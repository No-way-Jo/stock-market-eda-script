# Stock Market EDA Script: Monster Beverage Corp (MNST)

An interactive, end-to-end financial analytics application built in Python that streams live equity data to evaluate asset performance, pricing distributions, and volatility scales.

## Core Capabilities
* **Live Market Streaming:** Automates programmatic data ingestion from real-time market engines using `yfinance`.
* **Technical Indicator Modeling:** Computes rolling 20-day trend baselines (SMA) and daily asset volatility scales.
* **Interactive UI Interface:** Generates highly stylized, dark-mode responsive candlestick dashboards via `Plotly`.

## Project File Layout
* `stock_eda.py`: Complete Python source file containing data pipelines and technical aggregation rules.
* `monster_market_metrics.csv`: Generated output asset file hosting cleaned daily prices and performance values.

## Core Technologies
* Python, Pandas, yfinance, Plotly Data Engines
